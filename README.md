**Velvet Vault** — a top-down midnight heist game. One gallery room after closing time: a hooded thief slips past three patrolling guards with vision cones and two sweeping wall cameras, pockets at least three of the five treasures (Emerald Scarab, Golden Idol, Pearl Tiara, Sunset Canvas, and the Star Sapphire in the central vault), and escapes through the green EXIT door before dawn — while the alarm meter climbs whenever anyone has eyes on them. Sneak with Shift, blind the watchers with a smoke pellet (Q, two per heist), and read the cones before every move.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network — the game is plain static files under `game/`, with synthesised WebAudio sounds and nothing to install.
